Support

PureRunAir · Version 1.1.5 · iPhone only · Requires iOS 16.2 or later

PureRunAir is a minimalist running tracker. It records your route using GPS, computes distance, pace and elevation, exports your runs as GPX files, and shows live run progress on the Lock Screen and Dynamic Island. The app is fully offline — your runs never leave your device.

Contact

Need help, found a bug, or have a suggestion? Email vegaodm@outlook.com. To help us resolve issues quickly, please include:

  • Your iPhone model and iOS version (Settings → General → About)
  • The PureRunAir version (shown at Settings → Running, or on this page)
  • Steps to reproduce the problem, and what you expected to happen

Frequently Asked Questions

How does location permission work?

PureRunAir asks for While Using the App access when you start your first run. While a run is active, iOS keeps a continuous background location session, so recording continues with the screen locked or the app in the background — for example with the phone in a pocket or armband. An Always option may also be available in Settings on some iOS versions; it is optional. Your location is used only to record your route and never leaves the device. You can change access at any time in Settings → Privacy & Security → Location Services.

Does the app use the internet?

No. PureRunAir has no network connection at all. There is no account, no cloud, no analytics — all data stays on your iPhone.

Can I keep recording with the screen locked?

Yes. Start the run, then lock the screen and put the phone away. While the run is active the app keeps recording and updates the Live Activity, so you can see your time and distance at a glance.

How do I switch between kilometres and miles?

Tap the Speed / Pace cell in the four-cell header to toggle metric and imperial units. The run list and detail statistics update immediately; the Live Activity picks up the new unit on its next update.

Can I back up my runs or move them to another device?

Yes. The arrow buttons at the top of the run list export and import the local SQLite database. Export writes a snapshot you can keep in Files; importing replaces all current data with the chosen database. Import is disabled while a run is recording.

How do I export a run as a GPX file?

Tap Select in the top-right, choose one or more runs, then tap Share. PureRunAir generates the GPX file at that moment and iOS presents the standard share sheet, where you can save it to the Files app, AirDrop it, or send it to a service of your choice. The run detail screen is for viewing, not exporting.

I force-quit the app (or it was killed) in the middle of a run. Is the run lost?

No. The run is closed automatically the next time you open PureRunAir: it is marked as finished and its end time is set to the last recorded GPS point, so it appears in your list with the distance it had actually covered. Because trackpoints are written to disk in short batches, up to about 5 seconds at the very end of that run can be missing.

Why do elevation totals differ from what I remember (or from another app)?

Altitude from GPS is noisy, so PureRunAir smooths it before counting climb: a short median over the last few samples, then a 1 m threshold, so a single bad reading cannot invent a hill. That means the totals are deliberately conservative, and a run recorded with an older version can show a slightly different gain/loss than it did at the time. The recorded route and altitude samples themselves are unchanged — only the summary is recalculated.

Where can I view the Live Activity?

While a run is active, it appears on the Lock Screen on supported iOS 16.1+ devices, and in the Dynamic Island on iPhone 14 Pro and later. It updates about every 10 seconds. Tap it to open the run detail; it ends when you stop the run.

How do I delete my recordings?

Swipe a saved run to delete it, or tap Select, choose several runs, and use Delete. The run currently being recorded cannot be deleted. To remove everything, uninstall PureRunAir — there is no cloud copy, so deleting locally deletes everywhere.

The route looks wrong or has gaps. What can I do?

  • Make sure Location Services is enabled for the app and GPS signal is available (open sky).
  • Set the app's location access to While Using the App (Always is optional).
  • Enable Precise Location for the app in iOS settings.
  • If recording pauses unexpectedly, close other apps that may be competing for GPS and keep the phone where the antenna has a clear view of the sky.

What's new in 1.1.5

  • The Live Activity pace now uses moving time, matches the app, and follows metric/imperial units; Lock Screen text stays readable in light mode.
  • Route maps keep their true shape instead of being stretched horizontally.
  • Elapsed time covers the whole run, and the detail screen refreshes while a run is active.
  • Importing a database is safer: a bad file can no longer replace your runs, and import is blocked while recording.
  • Duplicate GPS fixes can no longer drop a batch of recorded points; leaving the app flushes the buffer to disk immediately.
  • If location access is revoked during a run, the run is closed cleanly.
  • GPX export is prepared off the main thread, so the run list stays responsive.

Troubleshooting Checklist

  • iOS 16.2 or later installed?
  • Location Services enabled with Precise Location?
  • Low Power Mode not restricting background activity during long runs?
  • Restarting the app (swipe it away and reopen) fixes many transient issues.
